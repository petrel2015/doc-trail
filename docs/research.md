# Research basis

Reviewed 2026-09-27. These are influences, not claimed conformance certifications or installed integrations. No framework was runtime-qualified during the document research.

| Source | Borrowed idea |
| --- | --- |
| [OpenAI Harness Engineering](https://openai.com/index/harness-engineering/) | Short agent entry as a map, repository knowledge and documentation maintenance checks |
| [OpenAI customization guidance](https://learn.chatgpt.com/docs/customization/overview#agents-guidance) | Scoped durable rules and routes for recurring mistakes |
| [OpenSpec concepts](https://github.com/Fission-AI/OpenSpec/blob/main/docs/concepts.md) | Current specs separate from proposed and archived changes |
| [Spec Kit persistence](https://github.com/github/spec-kit/blob/main/docs/concepts/spec-persistence.md) | Explicit distinction between living truth and preserved historical artifacts |
| [Claude Code memory](https://code.claude.com/docs/en/memory) | Modular, task/path-relevant guidance |
| [OpenCode rules](https://opencode.ai/docs/rules/) | Explicit routes to shared documents; links do not guarantee loading |
| [Cline Memory Bank](https://docs.cline.bot/best-practices/memory-bank) | Project explanation; active task context remains outside DocTrail |
| [Deep Agents](https://docs.langchain.com/oss/deepagents/code/overview) | Distinguish harness memory capabilities from a documentation standard |
| [ADR original article](https://www.cognitect.com/blog/2011/11/15/documenting-architecture-decisions) | Preserve superseded decisions and their rationale |
| [MADR](https://adr.github.io/madr/) | Context, alternatives, consequences and confirmation |
| [Diátaxis](https://www.diataxis.fr/start-here/) | Different reader needs for tutorials, how-to, reference and explanation |

DocTrail adds an explicit distinction between considered/tested/deployed alternatives, claim-level evidence and unknown motives, reconsideration conditions and bounded retrofit investigation. It does not copy an entire harness workflow into a documentation skill.
