# Development and acceptance

Python 3.10+ standard library; Git for history tests. No package install or build artifact is required. Run from the repository root:

```sh
python3 -m unittest discover -s tests -v
python3 skills/doctrail/scripts/doctrail.py check .
python3 -m compileall -q skills/doctrail/scripts tests
```

Required acceptance, defined before implementation:

- Short, routed skill entry; initialize, maintain and audit modes preserve their edit scope.
- Existing files survive inventory/history/check unchanged; no inferred motivation is generated by the helper.
- Bounded Git fixtures expose reversal subjects and history truncation without rewriting history.
- Missing local file links, duplicate IDs, invalid lifecycle states, missing predecessors and replacement cycles fail checks.
- No-Git inventory works; absent history or invalid input fails honestly where needed.
- Scope explicitly excludes dispatch and task handoffs; runtime evidence stays private.

Initial local validation: 13 unittest cases pass, including disposable Git history, literal path selection, read-only inventory, escapes, decision chains, cycles and CLI errors. Self-documentation file links and decision index are checked separately. Bytecode compilation is a syntax check, not a package build. Skill frontmatter is validated with the development host's Skill Creator validator.

Not yet qualified: independent agent behavioral trials, a complete real-world legacy retrofit, host auto-discovery, remote links, anchors and semantic accuracy. CI reproduces Python 3.10 tests and document checks; a workflow file alone is not a successful CI run. Do not claim fewer tokens or prevented regressions without measured field evidence.

Host-neutral packaging validation (2026-09-30): core skill structure, repository links and optional decision index pass checks. A complete copy of only `skills/doctrail/` into a disposable directory passes its local file-link check without the external product adapter. Optional adapter YAML parses. These checks establish package structure, not any host's discovery or model behavior.
