# DocTrail knowledge entry

DocTrail is an independent, host-neutral skill for progressive project documentation and significant decision history. The executable helper is read-only; semantic initialization and maintenance are agent-guided.

Read only the route needed:

- Run the skill: [SKILL.md](skills/doctrail/SKILL.md).
- Read directly or register with your host: [usage](docs/en/usage.md).
- Add optional product presentation metadata: [adapters](adapters/README.md).
- Modify helper behavior: [development and acceptance](docs/en/development.md), then [helper contract](skills/doctrail/references/tools.md).
- Change scope or document architecture: [architecture](docs/en/architecture.md), then [decision index](docs/decisions/README.md).
- Inspect research basis: [sources](docs/research.md).

No dispatcher, live task memory, automatic factual reconstruction or model calls. No external network requests in the helper. Inventory and Git reports may contain private names/subjects; do not publish raw output by default. No release, host activation or field effectiveness is implied by source files. Python 3.10+ and standard library; Git required only for history/metadata. [Current validation](docs/en/development.md).
